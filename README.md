# 🏡 우리 시골집 — 3D 웹 힐링 공간

Vite + React + Three.js(React Three Fiber)로 만든, 비 오는 시골집 마당과 아늑한 거실·부엌, 꼬마전구 아지트를 2등신 캐릭터로 걸어 다니는 힐링 공간입니다.
이미지·사운드 파일은 하나도 쓰지 않았습니다. 벽돌 질감, 얼굴, 체크무늬 같은 텍스처는 모두 캔버스로 그리고, 소리는 Web Audio API로 합성합니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

- 스마트폰에서 핀치 줌을 테스트하려면 PC와 같은 와이파이에서 터미널에 표시되는 `Network: http://192.168.x.x:5173` 주소로 접속하세요.
- 배포용 빌드: `npm run build` → `dist/` 폴더를 정적 호스팅(Vercel, Netlify, GitHub Pages 등)에 올리면 됩니다.

## 조작

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 이동 | WASD / 방향키 / 바닥 클릭 | 왼쪽 아래 조이스틱 / 바닥 탭 |
| 둘러보기 | 마우스 드래그 | 한 손가락 드래그 |
| 확대·축소 | 마우스 휠 | 두 손가락 핀치 |
| 방 이동 | 문 클릭, 근처에서 뜨는 `🚪` 버튼, 상단 드롭다운 | 같음 |

## 기능 요약

- **공간 3곳**: `우리집 마당`(빗소리 + 비 파티클), `거실과 부엌`(찌개 보글보글 + TV 소리 + 난로 장작 소리), `내 방 아지트`(오르골 음악)
- **아담한 방 + 높은 천장**: 거실 10×7m(천장 4.4m), 내 방 6×5m(천장 4m). 카메라는 좌우·뒤·천장 밖으로 나가지 않고, 앞벽은 바깥에서 보면 투명해져(돌하우스 방식) 시야가 답답하지 않습니다.
- **옅은 고동색 벽돌 벽**: 캔버스로 그린 벽돌·줄눈 텍스처에 범프맵을 더해 입체감을 냈습니다.
- **충돌 판정**: 벽, 침대, 책상 다리, 소파, 싱크대, 식탁·의자, 장독대, 텃밭, 감나무, 개집, 화분 등 모든 가구에 충돌체가 있습니다(`src/lib/collision.js`). 프레임이 느려도 이동을 잘게 나눠 판정하므로 벽을 뚫지 않습니다. 주소 뒤에 `?debug`를 붙이면 충돌 영역이 빨간 선으로 보입니다.
- **2등신 가족**: 주인공(바가지 머리), 엄마(묶음 머리 + 니트 + 꽃무늬 앞치마, 찌개 젓는 중), 아빠(둥근 안경 + 조끼, 소파에서 TV 시청), 오빠(후드티, 아지트 구석 빈백에서 게임 중). 오빠에게 다가가면 "야 모하냐?" 말풍선과 반응 버튼 3개가 뜹니다.
- **동물**: 마당의 백구와 감나무 가지 위 다람쥐. 둘 다 누르거나 소리 버튼을 누르면 움직입니다.
- **근접 자동 버튼**: 다람쥐·강아지·주전자·스케치북·가족·문 근처에 가면 화면 아래에 큰 버튼이 자동으로 뜹니다.
- **소리 켜짐 보장**: 첫 화면의 `🔊 소리 켜기 / 집으로 들어가기` 버튼을 누르는 순간 AudioContext를 만들고 resume한 뒤 무음 버퍼를 재생해 자동재생 차단을 풉니다. iOS에서는 `navigator.audioSession`도 playback으로 지정합니다. 오른쪽 위에서 음소거와 음량을 조절할 수 있습니다.

## 폴더 구조

```
├── index.html
├── package.json
├── vite.config.js
└── src
    ├── main.jsx              # 진입점 (iOS 페이지 확대 제스처 차단)
    ├── App.jsx               # Canvas + UI 조립
    ├── styles.css
    ├── audio/AudioEngine.js  # Web Audio 합성 배경음 + 효과음
    ├── lib/
    │   ├── store.js          # 전역 상태 (외부 라이브러리 없음)
    │   ├── shared.js         # 매 프레임 바뀌는 값 (플레이어/카메라/입력)
    │   ├── actions.js        # 장면 이동, 대화, 자세, 소리 재생
    │   ├── collision.js      # xz 평면 충돌 판정
    │   └── textures.js       # 절차적 캔버스 텍스처 (벽돌, 얼굴, 체크 등)
    ├── components/
    │   ├── Chibi.jsx         # 2등신 캐릭터 + 가족 외형 프리셋
    │   ├── Family.jsx        # 엄마/아빠/오빠 + 말풍선
    │   ├── Animals.jsx       # 백구, 다람쥐, 고양이 인형, 감
    │   ├── Player.jsx        # 이동/충돌/근접 검사
    │   ├── CameraRig.jsx     # 추적 카메라 + 드래그/핀치/휠
    │   ├── Effects.jsx       # 비, 김, 깜빡이는 불빛, 꼬마전구, 화면
    │   └── Prims.jsx         # 기본 도형, 벽돌 벽, 방 껍데기, 문, 창문
    ├── scenes/
    │   ├── config.js         # 장면별 카메라/스폰/상호작용 지점/대사
    │   ├── YardScene.jsx
    │   ├── LivingScene.jsx
    │   └── RoomScene.jsx
    └── ui/                   # 시작 화면, 상단바, 하단 버튼, 조이스틱 등
```

## 바꿔 보기

- 대사: `src/scenes/config.js`의 `NPC_LINES`, `BROTHER_CHOICES`
- 캐릭터 옷·머리 색: `src/components/Chibi.jsx`의 `LOOKS` (주인공 머리를 양갈래로 바꾸려면 `hair: 'pigtails'`)
- 오르골 멜로디: `src/audio/AudioEngine.js`의 `MELODY`
